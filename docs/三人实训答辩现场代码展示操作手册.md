### 场景 Y1：一个请求是怎么进后端的（开场必讲）

| 项 | 内容 |
| --- | --- |
| 软件 | VS Code |
| 文件 | backend/aqp-server/src/main/java/com/aqp/server/controller/StatsController.java |
| 行号 | 19–21（类注解）、34–38（stations 方法） |
| 验证页面 | Chrome 打开 http://127.0.0.1:8080/api/stations?pollutant=PM2.5 |

**展示代码（第 19–21 行 + 34–38 行）：**

~~~java
@RestController
@RequestMapping("/api")
public class StatsController {

    @GetMapping("/stations")
    public Result<List<StationStatVO>> stations(
            @RequestParam(value = "pollutant", required = false) String pollutant) {
        return Result.ok(statsService.stationStats(pollutant));
    }
}
~~~

**这段代码干什么：** 把 HTTP 请求映射到 Java 方法。@RestController 表示返回 JSON，@RequestMapping("/api") 是统一前缀，@GetMapping("/stations") 拼起来就是 /api/stations；pollutant 参数不是必填。

**怎么讲：** "浏览器访问 /api/stations?pollutant=PM2.5，先到 Controller 的 stations 方法。它只做两件事：接参数、调用 Service，自己不查数据库。返回值用 Result.ok 包一层，保证所有接口的返回格式一样。"

**老师可能追问：**
- 不传 pollutant 会怎样？→ required=false，Service 里默认 PM2.5。
- 为什么 Controller 里没有 SQL？→ 分层，SQL 在 Mapper。

**切到验证：** 打开接口地址，指出 JSON 里 code 为 0、data 是 12 条站点数据。

**回到代码：** 按 Alt+Tab 回 VS Code，说"数据是 Service 和 Mapper 查出来的，往下看"。

~~~python
def load_data():
    files = sorted(glob.glob(os.path.join(RAW_DIR, "*.csv")))
    if not files:
        raise SystemExit("未找到 CSV 文件，请检查目录：" + RAW_DIR)
    frames = [pd.read_csv(f) for f in files]
    df = pd.concat(frames, ignore_index=True)
    df["observation_time"] = pd.to_datetime(df[["year", "month", "day", "hour"]])
    return df, files


def check_duplicates(df):
    dup_mask = df.duplicated(subset=["station", "observation_time"], keep=False)
    groups = df[dup_mask].groupby(["station", "observation_time"]).size()
    return {
        "duplicate_rows": int(dup_mask.sum()),
        "duplicate_groups": int(len(groups)),
    }
~~~

### 场景 W3：三张统计表是怎么算出来的

| 项 | 内容 |
| --- | --- |
| 软件 | VS Code |
| 文件 | bigdata/ddl/04_spark_ads.sql |
| 行号 | 5–12（长表视图开头）、54–61（站点）、63–70（月度）、72–79（小时） |

**展示代码（第 5–12 行 + 54–61 行）：**

~~~sql
CREATE OR REPLACE TEMPORARY VIEW aq_long AS
SELECT station,
       CAST(year AS INT)  AS obs_year,
       CAST(month AS INT) AS obs_month,
       CAST(hour AS INT)  AS obs_hour,
       'PM2.5' AS pollutant,
       CAST(pm25 AS DOUBLE) AS value
FROM aq_air.ods_air_raw_v
UNION ALL
...

INSERT OVERWRITE DIRECTORY '/aq/ads/station_pollutant'
USING csv OPTIONS ('header' = 'true')
SELECT /*+ COALESCE(1) */ station, pollutant,
       ROUND(AVG(value), 2) AS avg_value,
       COUNT(value)         AS valid_cnt
FROM aq_long
GROUP BY station, pollutant;
~~~

**这段代码干什么：** 先用 UNION ALL 把六个污染物列转成"污染物 + 数值"的长表，再按不同维度 GROUP BY，算出平均值和有效样本数。

**怎么讲：** "原始表是一行里放六个污染物，画图不好按污染物切换，所以我先转成长表：一行只有一种污染物。然后三次 GROUP BY：按站点、按年月、按小时。平均值用 AVG，分母自动是非空值；COUNT(value) 只数非空，所以有效样本数和平均值是一起出来的。"

**老师可能追问：**
- 为什么是 72、288、144 行？→ 12 站乘 6 种、48 个月乘 6、24 小时乘 6。
- 为什么不写 INSERT INTO 表？→ 直接写 CSV 目录，再用 Hive 外部表映射，避免 Spark 和 Hive 元数据版本冲突。

**切到验证：** 打开 data/interim/ads/ads_station_pollutant.csv，看表头和第一行（Aotizhongxin 82.77 34139）；再看月度 CSV 的 2013-03 行。

**回到代码：** 指第 63–79 行，说"月度和小时候只是把 GROUP BY 换掉，结构一样"。

### 场景 T5：切换污染物为什么图表会刷新（必考）

~~~js
const pollutant = ref('PM2.5')

async function loadCharts() {
  loading.value = true
  try {
    const [s, m, h] = await Promise.all([
      fetchStations(pollutant.value),

})
~~~

## 9. 必须如实说的边界
