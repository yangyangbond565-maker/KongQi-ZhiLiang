## 1. 文档约定

### 1.1 优先级定义

| 优先级 | 含义 | 处理原则 |
| --- | --- | --- |
| P0（必做） | 缺了项目就不成立，答辩必须演示 | 阶段计划中优先排期，不完成不进入下一阶段 |
| P1（应做） | 明显提升完整性，时间允许就做 | P0 全部完成后再做 |
| P2（可选） | 加分项，可作为论文"展望" | 有余力再做，不做不影响验收 |

### 1.2 角色

系统不设登录与权限（V1 明确不做）。使用角色只有两个：

- **演示者/评审者**：打开页面看数据、改筛选条件、导出结果。
- **开发者（你）**：跑数据作业、维护接口、核对数字。

### 1.3 术语通俗解释

| 术语 | 通俗解释 |
| --- | --- |
| ODS（原始层） | 原封不动存放下载来的数据，谁都不许改 |
| DWD（明细层） | 清洗规范后的一行一小时一条记录 |
| ADS（应用层） | 事先算好的统计结果，专门给页面和接口用 |
| 聚合 | 把很多行"合并"成一行，例如按站点求平均值 |
| 分页 | 一次只返回一部分数据，避免一次传几万行 |
| 口径 | 数字是怎么算出来的，例如"均值是否排除缺失值" |

## 2. 功能需求

### 模块一：数据管理（DM）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-DM-01 | 展示数据集名称、来源、许可、记录总数、字段数、时间范围 | P0 | 页面显示的记录数与 Hive 中 select count(1) 一致；时间范围与 min/max 一致 |
| FR-DM-02 | 展示字段信息（字段名、含义、类型、单位、是否可空） | P0 | 与 03 数据字典完全一致，字段数不少于 17 个原始字段 |
| FR-DM-03 | 原始数据预览（前 N 行） | P0 | 预览内容与 HDFS 原始文件前几行一致；页面标注"原始数据，未清洗" |
| FR-DM-04 | 缺失值检查：每个字段缺失数量与缺失率 | P0 | 12 个字段的缺失数之和等于各字段逐一 count 的结果；可导出 |
| FR-DM-05 | 重复记录检查：按"站点 + 观测时间"判重 | P0 | 输出重复组数与涉及记录数；若为 0 也要显示 0，不能省略 |
| FR-DM-06 | 异常值检查：负浓度、非法时间、超范围气象值 | P0 | 每类异常有独立计数；抽样展示具体记录 |
| FR-DM-07 | 清洗前后记录数对比 | P0 | 显示 原始数 / 清洗保留数 / 剔除数 / 标记数，且满足 原始数 = 保留数 + 剔除数 |
| FR-DM-08 | 清洗规则与结果记录（规则编号、说明、影响行数） | P0 | 规则编号与 03 文档的 DQ 编号一一对应 |
| FR-DM-09 | 原始数据只读留档 | P0 | 原始目录无写入、无覆盖；清洗结果写入新目录 |
| FR-DM-10 | 按站点查看该站数据质量 | P1 | 每个站点有独立缺失率与有效样本数 |
| FR-DM-11 | 数据质量总评分/等级 | P2 | 评分规则必须写清公式，不得拍脑袋 |

**关键约束**：不得把缺失值填 0；不得静默删除异常行（删除必须有规则编号与计数）。

### 模块二：大数据存储与处理（BH）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-BH-01 | 原始 CSV 上传至 HDFS 原始层 | P0 | hdfs dfs -ls 能看到 12 个站点文件，总大小与本地一致 |
| FR-BH-02 | 建立 Hive 原始表（外部表，指向原始目录） | P0 | desc formatted 显示字段与原始表头一致；drop 表不删数据 |
| FR-BH-03 | Spark SQL 完成清洗并写入明细层（Parquet） | P0 | 明细层可按分区查询；行数与清洗报告一致 |
| FR-BH-04 | 建立 Hive 明细表（外部表映射明细层） | P0 | Hive 查询明细行数 = Spark 写出行数 |
| FR-BH-05 | Spark SQL 生成站点、时间、小时、质量四类 ADS 结果 | P0 | 每张 ADS 表有唯一主键口径（如 station + month），无重复行 |
| FR-BH-06 | 建立 Hive ADS 表并可 SQL 复算 | P0 | 用 Hive 直接查询 ADS 表结果与页面数字一致 |
| FR-BH-07 | 分析结果同步到应用库（MySQL）供后端读取 | P0 | MySQL 中 ADS 表行数与 Hive 一致 |
| FR-BH-08 | 作业可重复执行且幂等 | P0 | 同一份输入跑两次，结果不翻倍、不重复 |
| FR-BH-09 | 作业日志与参数可追溯 | P0 | 每次运行记录：时间、参数、输入行数、输出行数、耗时 |
| FR-BH-10 | 使用分区（year/month 或 station）提高查询效率 | P1 | 分区字段出现在表结构中，查询能命中分区 |
| FR-BH-11 | 增量更新（只处理新增月份） | P2 | 有明确的增量边界规则 |

**说明**：FR-BH-07 是本项目"大数据 → 应用"的关键交接点，方案对比见 04 文档第 4 节。

### 模块三：空气质量统计分析（ST）

| 编号 | 需求 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-ST-01 | 站点维度：各站点 PM2.5/PM10/SO2/NO2/CO/O3 均值、中位数、最大值、有效样本数 | P0 | 抽样 2 个站点手工复算，误差 < 0.01 |
| FR-ST-02 | 污染物维度：每种污染物的分布特征（均值、P95、超标? 不做等级） | P0 | 不出现 AQI 或"优良天数"等未定义指标 |
| FR-ST-03 | 时间维度：按日、按月统计浓度变化 | P0 | 月份数为 48（2013-03 至 2017-02）或与数据实际一致 |
| FR-ST-04 | 小时维度：0–23 时均值曲线 | P0 | 每个站点 24 个点齐全；缺失小时要显示缺口而非补 0 |
| FR-ST-05 | 站点数据质量对比：各站缺失率、有效天数 | P0 | 与模块一 DQ 结果一致 |
| FR-ST-06 | 多维筛选：站点 + 日期范围 + 污染物 | P0 | 筛选组合变化后结果随之变化，不刷新整页 |
| FR-ST-07 | 结果可追溯到 SQL | P0 | 每个统计卡片/图表旁可查看"数据来源表 + SQL" |
| FR-ST-08 | 季节/星期维度分析 | P1 | 季节划分规则写进文档（3–5 春、6–8 夏、9–11 秋、12–2 冬） |
| FR-ST-09 | 站点间差异显著性（简单检验） | P2 | 必须说明方法与假设，不夸大结论 |

**口径强制要求**：所有均值均使用"非空值的算术平均"，样本数为该组非空值个数；文档与接口注释必须写明。禁止用 0 参与平均。

| 编号 | 需求 | 优先级 | 验收标准 |

| FR-DB-08 | 单位标注：所有浓度图表必须带单位，单位以官方数据字典核验结果为准（CO 单位存在 μg/m³ 与 mg/m³ 两种表述，核验前不得写死） | P0 | 图例/坐标轴带有单位，且与 03 文档第 3.1 节结论一致 |

| NFR-07 | 可靠性 | 大数据环境停机时，大屏仍可展示已同步的结果（降级可用） | 关闭虚拟机后刷新页面 |

### 4.2 可选（P1/P2）

- 站点级质量细分、分区优化、季节/星期分析、大屏自适应、导出说明、导出底表、图表清单。
- 进阶：Hive JDBC 直连查询、增量更新、图表下载、数据质量评分。

### 4.3 暂不实现（V1 明确不做）

| 功能 | 不做的理由 |
| --- | --- |
| 实时空气质量监测 | 数据是历史数据，没有数据源推流；做了就是假实时 |
| 爬虫自动采集 | 与课程目标无关，且违反数据使用原则 |
| 机器学习预测 | 需先保证基础链路，预测结论也需独立验证 |
| 全国城市排名 | 数据集只有北京 12 个站点，编造排名即造假 |
| 用户权限系统 | 单机演示场景无必要，属于堆技术 |
| 地图可视化 | 数据集不含经纬度；用外部坐标表拼接会产生未核实数据 |
| AQI 与等级判定 | 数据集无 AQI 字段；标准计算需完整核验，V1 不做 |

## 5. 验收标准（Definition of Done）

一个需求"完成"必须同时满足：

1. 功能实现，且通过该需求的验收标准。
2. 数据从真实链路而来，可用 SQL 复算。
3. 后端接口有统一返回结构，异常有处理。
4. 前端页面无控制台报错，筛选联动正常。
5. 相关文档已更新（数据字典/接口说明/运行说明）。
6. 代码已提交 Git，提交信息能说明改了什么。

**整体验收（阶段七执行）**：

| 项 | 通过条件 |
| --- | --- |
| 数据链路 | 从原始 CSV 到页面数字全链路可重跑 |
| 口径一致 | 抽 5 个指标，页面 = 接口 = SQL = Matplotlib |
| 异常处理 | 大数据环境停机时页面仍可用（降级） |
| 性能 | 满足 NFR-01 |
| 演示 | 8 分钟完整演示不卡壳、不出错 |
