## 2. 字段分层原则

本项目把字段分三类，任何统计口径都必须说明用的是哪一类：

| 类别 | 定义 | 存在位置 |
| --- | --- | --- |
| **原始字段** | 下载即得，改名都不改，保持原样 | ODS 层 |
| **规范化字段** | 由原始字段直接映射而来，语义不变，只统一命名与类型 | DWD 层 |
| **衍生字段** | 由规范化字段计算得到，原始数据中不存在 | DWD/ADS 层 |

> 关键区分：pm25 是"规范化字段"（PM2.5 换了个名字），而 pm25_month_avg 是"衍生字段"（算出来的）。论文里不能把衍生字段写成"数据集提供"。

## 3. 原始字段（ODS 层）

| # | 原始字段 | 含义 | 类型 | 单位 | 说明与核验要点 |
| --- | --- | --- | --- | --- | --- |
| 1 | No | 记录序号 | int | 无 | **每个站点文件内独立编号**，不是全局唯一，不能当主键 |
| 2 | year | 年 | int | 年 | 2013–2017 |
| 3 | month | 月 | int | 月 | 1–12 |
| 4 | day | 日 | int | 日 | 1–31，需与年月组合校验合法性 |
| 5 | hour | 时 | int | 时 | 0–23 |
| 6 | PM2.5 | 细颗粒物浓度 | double | μg/m³ | 缺失以 NA 表示 |
| 7 | PM10 | 可吸入颗粒物浓度 | double | μg/m³ | 缺失以 NA 表示 |
| 8 | SO2 | 二氧化硫浓度 | double | μg/m³ | 缺失以 NA 表示 |
| 9 | NO2 | 二氧化氮浓度 | double | μg/m³ | 缺失以 NA 表示 |
| 10 | CO | 一氧化碳浓度 | double | **待核验** | 见 3.1 单位风险 |
| 11 | O3 | 臭氧浓度 | double | μg/m³ | 缺失以 NA 表示 |
| 12 | TEMP | 气温 | double | ℃ | 可能为负值 |
| 13 | PRES | 气压 | double | hPa | 数值约 1000 上下 |
| 14 | DEWP | 露点温度 | double | ℃ | 可能为负值 |
| 15 | RAIN | 降水量 | double | mm | 大量为 0，0 是真实值不是缺失 |
| 16 | wd | 风向 | string | 方位 | 中文方位（如 北、东北）或英文缩写，需确认 |
| 17 | WSPM | 风速 | double | m/s | 缺失以 NA 表示 |
| 18 | station | 站点名称 | string | 无 | 英文拼写，如 Aotizhongxin |

### 3.1 单位风险（必须核验，不得想当然）

**CO 的单位在不同资料中存在 μg/m³ 与 mg/m³ 两种表述，两者相差 1000 倍。** 处理原则：

1. 以官网数据字典的文字表述为准；
2. 同时用数值量级交叉验证（若数值集中在几百到两千，接近 μg/m³ 量级；若集中在 0.5–2，则是 mg/m³）；
3. 核验完成前，前端图表与文档**不得写死单位**，只能标注"单位见数据字典"。

这条规则同样适用于所有污染物字段：单位错一个数量级，整篇论文的数字都会被质疑。

## 4. 规范化字段（DWD 层）

### 4.1 字段映射表

| DWD 字段 | 类型 | 来源 | 规则 |
| --- | --- | --- | --- |
| record_id | string | 计算 | station + '_' + observation_time，唯一标识一条记录 |
| observation_time | timestamp | 计算 | year-month-day hour:00:00 组合而成 |
| station_name | string | station | 去空格，保留原拼写 |
| pm25 | double | PM2.5 | 直接映射，NA → NULL |
| pm10 | double | PM10 | 同上 |
| so2 | double | SO2 | 同上 |
| no2 | double | NO2 | 同上 |
| co | double | CO | 同上 |
| o3 | double | O3 | 同上 |
| temperature | double | TEMP | 同上 |
| pressure | double | PRES | 同上 |
| dew_point | double | DEWP | 同上 |
| rainfall | double | RAIN | 同上（0 保留为 0） |
| wind_direction | string | wd | 去空格；空字符串 → NULL |
| wind_speed | double | WSPM | NA → NULL |
| data_quality_flag | string | 计算 | 质量标记，见第 9 节 |
| source_file | string | 计算 | 记录来源文件名，便于追溯 |

### 4.2 命名规范

- 数据库/字段统一小写下划线：pm25、observation_time。
- 不使用中文列名（前端显示时再做中文映射）。
- 布尔字段以 is_ 开头：is_weekend。
- 统计字段带后缀表示口径：_avg（均值）、_cnt（样本数）、_p95（95 分位）。

| 衍生字段 | 计算规则 | 用途 |
| --- | --- | --- |
| obs_date | date(observation_time) | 按日聚合 |
| obs_year | year(observation_time) | 按年聚合 |
| obs_month | month(observation_time) | 按月聚合 |
| obs_hour | hour(observation_time) | 按小时聚合 |

## 6. 数据质量规则（DQ）

每条规则都有编号，清洗日志与大屏"清洗规则"表格必须引用同一编号。

| 编号 | 规则名称 | 判定条件 | 处理动作 | 是否删除 | 记录内容 |
| --- | --- | --- | --- | --- | --- |
| DQ-01 | 文件格式检查 | 文件可读、表头列数符合预期、编码为 UTF-8 | 不合格则该文件停止处理并报错 | 否 | 文件名、实际列数、期望列数 |
| DQ-02 | 字段类型转换 | 数值列可转为 double | 转换失败置 NULL 并标记 | 否 | 失败行数、原始值样例 |
| DQ-03 | 缺失标记识别 | 值为 NA、空串、null | 统一转为 NULL | 否 | 各字段缺失数与缺失率 |
| DQ-04 | 时间合法性 | year/month/day/hour 组合能构成真实时间（如 2 月 30 日非法） | 非法则标记并剔除 | 是 | 非法记录数及样例 |
| DQ-05 | 时间范围检查 | observation_time 不早于 2013-03-01，不晚于 2017-02-28 23:00 | 越界标记并剔除 | 是 | 越界记录数 |
| DQ-06 | 重复记录检查 | (station_name, observation_time) 重复 | 保留一条，其余剔除并计数 | 是（重复项） | 重复组数、删除条数 |
| DQ-07 | 负数浓度检查 | pm25/pm10/so2/no2/co/o3 小于 0 | 置 NULL 并标记 | 否 | 每字段负数个数 |
| DQ-08 | 气象值范围检查 | temperature ∉ [-40, 50]；pressure ∉ [850, 1100]；wind_speed ∉ [0, 40]；rainfall 小于 0 | 越界置 NULL 并标记 | 否 | 每字段越界个数 |
| DQ-09 | 常量列/空列检查 | 某列全部为 NULL 或全部同值 | 报告，不删 | 否 | 列名、取值分布 |
| DQ-10 | 站点一致性检查 | 文件内 station 取值唯一且与文件名一致 | 不一致则告警 | 否 | 冲突记录数 |
| DQ-11 | 单位核验 | 与官方数据字典文字比对 + 数值量级合理性 | 不一致则停止并修正字段定义 | 否 | 核验结论 |
| DQ-12 | 全空行检查 | 除时间与站点外全部为 NULL | 标记为空观测 | 否（保留，参与缺失统计） | 空观测行数 |

### 6.1 关于阈值（DQ-08）的说明

上面的 [-40, 50]℃、[850, 1100]hPa、[0, 40]m/s 是**初筛阈值**，用于发现明显录入错误，不代表气象学上"不可能"。正式使用时应在阶段二用箱线图（1.5 倍 IQR）复核，并把最终阈值写回本表。

**不得**因为"看起来不合理"就删除整行数据：删数据必须有规则编号、有计数、有说明。

### 6.2 禁止事项

| 禁止 | 原因 | 正确做法 |
| --- | --- | --- |
| 把 NA 填成 0 | 0 是真实浓度值（如降水为 0），会严重拉低均值 | 保持 NULL，统计时用有效样本数 |
| 直接覆盖原始 CSV | 无法回溯，无法自证 | 原始层只读，结果写新目录 |
| 无记录地 dropna | 说不清丢了什么 | 每条删除规则对应 DQ 编号并计数 |
| 用均值填充缺失后当真实值分析 | 会人为制造集中趋势 | 如需填充，必须标注"填充值"并单独分析 |
| 把污染物浓度叫 AQI | 概念不同，量纲不同 | 一律称"浓度" |

## 8. 清洗流程（五步）

1. **格式核验**（DQ-01）：读表头、比对列数与编码。
2. **类型与缺失处理**（DQ-02、DQ-03）：数值转换，NA → NULL。
3. **时间构造与合法性校验**（DQ-04、DQ-05）：拼 observation_time，剔除非法时间。
4. **重复与异常处理**（DQ-06、DQ-07、DQ-08）：去重、负值置空、越界置空，全部留标记。
5. **汇总输出**（DQ-09 ~ DQ-12）：生成质量报告 + 写入 DWD 分区表。

### 8.1 记录数守恒（必须成立）

~~~
原始记录数 = DWD 保留记录数 + 剔除记录数
DWD 保留记录数 = 完整记录数 + 含缺失记录数（data_quality_flag 不为 OK）
~~~

两部分数字对不上，说明清洗逻辑有 bug 或统计口径不一致，必须查明后再进入下一阶段。

## 9. 数据质量标记（data_quality_flag）

采用"主状态 + 明细标记"的简单设计（便于初学者理解与 SQL 统计）：

| 取值 | 含义 | 判定 |
| --- | --- | --- |
| OK | 六个污染物字段与主要气象字段均非空 | 无任何问题 |
| MISSING | 存在缺失，但时间与站点合法 | 至少一个字段为 NULL |
| OUT_OF_RANGE | 存在被置空的越界/负值 | 触发 DQ-07 或 DQ-08 |
| EMPTY_OBS | 除时间与站点外全部为空 | DQ-12 |

补充列 flag_detail（string）记录具体字段，例如 negative:pm25;missing:o3，便于排查。

> 设计取舍：不做多列布尔标记，避免 12 个布尔列让初学者迷失；一个状态列 + 一个明细列足够支撑模块一的统计。

## 10. 统计口径约定（全项目统一）

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 均值 | 非空值的算术平均 | 分母是该组非空个数，不是总行数 |
| 有效样本数 | 该组非空值个数 | 必须与均值一起展示 |
| 缺失率 | 1 - 有效样本数 / 该组总行数 | 以百分比展示，保留 2 位小数 |
| 中位数 | 非空值的中位数 | Spark 用 percentile_approx 或精确 percentile |
| P95 | 非空值的 95 分位 | 需说明是近似分位还是精确分位 |
| 站点均值 | 该站所有有效小时值的平均 | **不是**"先按月平均再平均"，避免小样本月份权重失真 |
| 月度均值 | 该月所有有效小时值的平均 | 同上 |
| 小时均值 | 该小时在所选时间段内所有日期的平均 | 用于日内变化曲线 |

**特别提醒**："均值的均值"通常不等于"总均值"。凡涉及跨月再汇总，必须在文档写明算法，并保证页面与 SQL 一致。
