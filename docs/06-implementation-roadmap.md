### 3.6 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| 下载 403/超时 | 网络或代理问题 | 先修网络；必要时浏览器手动下载后放入 data/raw |
| 中文路径导致脚本报错 | Windows 编码问题 | 数据放英文路径，或脚本统一用 UTF-8 读写 |
| pandas 读出的列数不对 | 分隔符不是逗号 / 有 BOM | 试 sep=','、encoding='utf-8-sig' |
| 虚拟机 SSH 连不上 | NAT 网段或防火墙 | 确认 IP、ping 通、sshd 状态；必要时改用 NAT 端口映射 |
| HDFS 启动失败 | 未格式化 / 多次格式化导致 clusterID 不一致 | 查看 logs，必要时清空 data 目录后重新 format |
| MySQL 连不上 | 服务未启动 / 账号权限 | 启动服务，确认 host 与授权 |

## 4. 阶段三：HDFS、Hive 与 Spark SQL 的数据处理

### 4.1 目标

把 CSV 变成可查询的 Hive 表，用 Spark SQL 完成清洗与聚合，产出 4 张 ADS 结果表，并把结果同步到 MySQL。

### 4.2 具体任务

| # | 任务 | 技术 | 产物 |
| --- | --- | --- | --- |
| 1 | 建 HDFS 目录（ods/dwd/ads） | hdfs dfs -mkdir | 目录树 |
| 2 | 上传原始 CSV 并设只读 | hdfs dfs -put/-chmod | /aq/ods/air_quality |
| 3 | 建原始外部表 | Hive DDL | ods_air_raw |
| 4 | 编写清洗作业 01_clean.py | PySpark | DWD Parquet + 质量报告 |
| 5 | 建明细外部表 | Hive DDL | dwd_air_hourly |
| 6 | 编写聚合作业 02_aggregate.py | PySpark | 4 张 ADS 表 |
| 7 | 建 ADS 外部表 | Hive DDL | ads_station_summary 等 |
| 8 | 编写导出作业 03_export_mysql.py | PySpark JDBC | MySQL 表 |
| 9 | 记录作业日志 | log4j / 自写 log | bigdata/logs |
| 10 | 数据质量报告 | Hive/Spark SQL | docs/08-quality-report.md |

### 4.3 预期产物

- HDFS 三层目录与文件
- 6 张以上 Hive 表（ODS/DWD/ADS）
- 3 个 PySpark 作业脚本 + 3 个 DDL 脚本
- 数据质量报告（缺失率、重复数、异常数、清洗前后行数）
- MySQL 中 4 张结果表

### 4.4 验收标准

- [ ] Hive 查 ODS 行数 = 原始文件行数
- [ ] DWD 行数 + 剔除行数 = 原始行数（记录数守恒）
- [ ] DWD 中不存在负浓度、不存在非法时间
- [ ] 4 张 ADS 表无重复主键
- [ ] 同一作业跑两次，结果行数不变（幂等）
- [ ] MySQL 行数与 Hive 一致
- [ ] 任取一个站点某月均值，手工用 Python 复算一致（误差 < 0.01）

### 4.5 常见错误与解决

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| Hive 表查不到数据 | LOCATION 路径不对 / 文件格式不匹配 | desc formatted 看路径；确认 STORED AS 与文件格式一致 |
| Spark 写 HDFS 权限拒绝 | 用户与目录权限不匹配 | 用 hdfs 用户或改目录 owner |
| 中文注释乱码 | Hive 元数据库字符集 | 建库时指定 utf8，或注释用英文 |
| 作业重复跑数据翻倍 | 覆盖写没设对 | 用 mode("overwrite")，或先删分区 |
| JDBC 写入 MySQL 报时区错 | serverTimezone 未设 | URL 加 ?serverTimezone=Asia/Shanghai |
| Spark 内存溢出 | 本地内存太小 | 降低 shuffle 分区、加 driver memory |

### 4.6 进入下一阶段的前置条件

MySQL 四张表数据齐全且与 Hive 一致；数据质量报告完成。
